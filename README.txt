DhanyTV Android TV (WebView layar penuh)

1. Ubah alamat server default di app/src/main/java/com/dhanytv/app/MainActivity.java (DEFAULT_URL),
   atau ubah nanti di dalam aplikasi dengan tombol MENU pada remote.
2. Upload seluruh folder ini ke repo GitHub (termasuk folder .github).
3. Buka tab Actions > Build APK > Run workflow. Setelah selesai, unduh artifact "DhanyTV-apk" (app-debug.apk).
4. Pasang APK di Android TV.
